# 🔐 PassGuard

**PassGuard** adalah aplikasi Android open-source untuk **mengecek kekuatan password**, memberikan **estimasi waktu pembobolan**, serta **tips perbaikan keamanan**. Aplikasi ini dibuat untuk membantu pengguna memahami seberapa aman password yang mereka gunakan.

---

## 📱 Informasi Aplikasi
- **Nama Aplikasi:** PassGuard  
- **Package Name:** `com.passguard.rafka`  
- **Platform:** Android  

---

## ✨ Fitur

### 🔑 Password Input
- Input password secara langsung
- Password **tidak disimpan**
- Opsi tampilkan / sembunyikan password

### 📊 Penilaian Kekuatan
- Kategori: **Weak / Medium / Strong**
- Penilaian berdasarkan:
  - Panjang password
  - Huruf besar & kecil
  - Angka
  - Simbol

### ⏱️ Estimasi Waktu Dibobol
- Perkiraan waktu pembobolan password
- Ditampilkan dalam satuan:
  - Detik
  - Menit
  - Jam
  - Tahun

> Estimasi bersifat **perkiraan edukatif**, bukan jaminan absolut.

### 💡 Tips Perbaikan
- Saran menambah panjang password
- Gunakan kombinasi huruf besar, angka, dan simbol
- Hindari password umum
